# Skills

Personal skills for agentic workflows.

## Coding conventions

- [bash-conventions](bash-conventions/SKILL.md): Conventions for new and
  substantially rewritten Bash code.
- [python-conventions](python-conventions/SKILL.md): Conventions for new and
  substantially rewritten Python code.
- [rust-conventions](rust-conventions/SKILL.md): Conventions for new and
  substantially rewritten Rust code.

## Development workflows

- [github-conflicts](github-conflicts/SKILL.md): Resolve merge conflicts in
  GitHub pull requests, with the [gh-stack skill] for stack rebases.
- [review-loop](review-loop/SKILL.md): Run independent review-and-fix passes
  with native subagents when the user requests iterative review and correction.

## Conversation management

- [rename-thread](rename-thread/SKILL.md): Rename the current conversation or
  workspace using the active app's native tools.

[gh-stack skill]: https://github.com/github/gh-stack/tree/main/skills/gh-stack
